## 🚀 How to Run

### Step 1: Start the Server
Open a terminal/command prompt and run:
```bash
python run_server.py
```

You should see:
```
======================================================================
🚀 HYBRID GEOSPATIAL RETRIEVAL API SERVER
======================================================================

📝 Server will start on: http://127.0.0.1:5000

✅ Test Commands (use in another terminal):
...
Starting server...
 * Running on http://127.0.0.1:5000
```

### Step 2: Make Requests (in another terminal)

#### Health Check:
```bash
curl http://127.0.0.1:5000/api/health
```

#### Default Query (Event 3651, 500m radius):
```bash
curl http://127.0.0.1:5000/api/hybrid_geospatial_retrieval
```

#### Custom Query (1km radius):
```bash
curl "http://127.0.0.1:5000/api/hybrid_geospatial_retrieval?event_id=3651&radius_meters=1000"
```

## 📝 API Endpoints

### 1. GET /api/health
Returns server status

### 2. GET /api/hybrid_geospatial_retrieval
Performs geospatial search with optional parameters:
- `event_id`: Event ID (default: 3651)
- `radius_meters`: Search radius (default: 500)

## 🔍 Example Requests with Pretty Output

### Windows CMD:
```bash
curl http://127.0.0.1:5000/api/hybrid_geospatial_retrieval | python -m json.tool
```

### Windows PowerShell:
```powershell
$response = Invoke-WebRequest -Uri "http://127.0.0.1:5000/api/hybrid_geospatial_retrieval"
$response.Content | ConvertFrom-Json | ConvertTo-Json
```

### Linux/Mac:
```bash
curl http://127.0.0.1:5000/api/hybrid_geospatial_retrieval | jq .
```
