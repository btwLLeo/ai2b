🐛 TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════

Problem: "Connection refused"
  → Make sure START_API.bat is running in another window

Problem: "curl: command not found"
  → Update Windows 10/11 or install curl separately

Problem: "Flask not found"
  → Run: pip install flask

Problem: "Port 5000 in use"
  → Edit api_server.py, change port=5000 to port=5001
